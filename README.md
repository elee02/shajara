# Shajara (Шаджара / Yetti Pusht)

A digital genealogy and family tree platform tailored for preserving lineage (such as the Uzbek 7-ancestor tradition / *yetti pusht*), enabling collaborative data entry with granular row-level privacy and high-resolution printable PDF exports.

## Core Features
- **Collaborative Family Tree**: Shareable access link for relatives across any smartphone or browser.
- **Granular Permissions**: Authenticated users can only edit or modify entries they personally created.
- **Export & Print**: Automated tree layout exported to printable PDF formats (A4, A3, A2, and poster sizes).
- **Self-Hostable**: Deployable on any Linux VPS (Hetzner, DigitalOcean, local Uzbek data centers, etc.) or container runtime.
